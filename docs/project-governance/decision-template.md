# قالب ثبت تصمیم

شناسه بعدی را از [دفتر تصمیم‌ها](decisions.md) بردارید و شناسه قدیمی را دوباره مصرف نکنید. تاریخ نامعلوم را «نامشخص؛ گردآوری در …» بنویسید.

- شناسه و عنوان:
- تاریخ تصمیم / آخرین بازنگری:
- دسته: محصول / UI / امنیت / مالی / داده / زیرساخت / آزمون / همکاری
- منبع و تصمیم‌گیرنده: درخواست کاربر، بررسی کد، یا پیشنهاد عامل
- مسئله و زمینه:
- تصمیم نهایی:
- دلیل انتخاب:
- گزینه‌های بررسی‌شده و علت رد/تعویق:
- وضعیت تصویب: پیشنهادی / تأییدشده / جایگزین‌شده
- وضعیت اجرا: برنامه‌ریزی / جزئی / دارای شاهد کد / نیازمند تطبیق
- شاهد آزمون: تازه با دستور/تاریخ/محیط / تاریخی / تأیید کاربر / آزموده‌نشده
- مسیر فایل‌ها و مستندات مرتبط:
- اثر روی رودمپ و معیار پذیرش:
- جایگزین تصمیم / اصلاحیه قبلی:
- پرسش‌های باز و محدودیت‌ها:

پس از تغییر تصمیم: سابقه قبلی حفظ، قاعده جاری اصلاح، رودمپ و وضعیت و handoff هماهنگ و لینک‌ها بررسی شوند. راه‌حل حدسی عامل به‌عنوان تصمیم قطعی کاربر ثبت نشود.
