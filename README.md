# سامانه یکپارچه دیاکو

سامانه تحت وب حسابداری، خرید و فروش، انبار، تولید، گارانتی و خدمات پس از فروش برای اجرای داخلی روی کامپیوتر سرور و دسترسی رایانه، تبلت و گوشی از شبکه محلی.

## اجرای محلی

1. Node.js و PostgreSQL را نصب کنید.
2. فایل `.env` واقعی را براساس `.env.example` فقط روی سرور بسازید.
3. وابستگی‌ها را با `npm install` نصب کنید.
4. پایگاه داده را با `npm run db:migrate` آماده کنید.
5. نسخه عملیاتی را با `npm run build` بسازید و با `npm start` اجرا کنید.
6. برنامه روی خود سرور از `http://127.0.0.1:4173` و در شبکه با `http://IP-SERVER:4173` در دسترس است.

در اولین اجرا، مدیر سامانه را با رمزی حداقل ۱۰ نویسه‌ای شامل حرف بزرگ انگلیسی، حرف کوچک انگلیسی و عدد تعریف کنید.

## بازیابی مدیر سامانه

بازیابی هیچ فاکتور، سند، موجودی، پرونده گارانتی یا داده عملیاتی را حذف نمی‌کند.

1. فقط روی کامپیوتر سرور، ترمینال را با گزینه **Run as administrator** باز کنید.
2. وارد پوشه برنامه شوید و `npm run recovery` را اجرا کنید.
3. در پنجره محلی بازشده مدیر را انتخاب و رمز جدید را دوبار وارد کنید.
4. پس از موفقیت، همه نشست‌های قبلی همان مدیر بسته می‌شوند و سابقه عملیات در ممیزی ثبت می‌شود.

ابزار بازیابی فقط روی `127.0.0.1` و برای ده دقیقه فعال است، رمز قبلی را نمایش نمی‌دهد و هیچ مسیر بازیابی عمومی در LAN ایجاد نمی‌کند.

## امنیت

- رمزها با `scrypt` و Salt تصادفی ذخیره می‌شوند و متن رمز در دیتابیس قرار نمی‌گیرد.
- نشست ورود در Cookie دارای HttpOnly نگهداری و طبق تنظیم سرور منقضی می‌شود.
- پس از پنج ورود ناموفق، حساب برای ۱۵ دقیقه موقتاً قفل می‌شود.
- API عملیاتی بدون ورود و مجوز قابل استفاده نیست.
- تغییر رمز مدیر، قفل ورود را پاک و تمام نشست‌های پیشین او را باطل می‌کند.
- رویدادهای مهم در جدول ممیزی append-only ثبت می‌شوند.
- `.env`، دیتابیس، نسخه پشتیبان، رمز و توکن هرگز در Git قرار نمی‌گیرند.

## بررسی نسخه

- TypeScript: `npm run lint`
- آزمون‌ها: `npm test`
- ساخت نسخه عملیاتی: `npm run build`
